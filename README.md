# Hangman
Hangman is a terminal-based word guessing game built in C++. The game randomly selects a word from easy, medium, or hard difficulty categories, and the player must guess the word one letter at a time before running out of lives. The project includes ASCII-art Hangman stages, a scoring system based on performance, difficulty-specific hint limits, input validation, and replay functionality.

# Features:
  - Three difficulty levels (Easy, Medium, Hard)
  - Random word selection
  - ASCII-art Hangman display
  - Hint system with limited hints per difficulty
  - Score tracking across multiple rounds
  - High Score tracking system
  - Duplicate guess detection
  - Input validation
  - Play-again option
